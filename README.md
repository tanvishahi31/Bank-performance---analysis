Banking Transaction Analysis Dashboard | Power BI

Project Overview

This project focuses on analyzing banking transaction data through an interactive Power BI dashboard. It presents transaction activity, customer and account information, and key performance indicators to support data-driven insights.

Tools & Technologies

- Power BI
- DAX measures
- Data visualization
- Interactive filters and slicers

Dashboard Features

- Key performance indicator (KPI) cards
- Monthly transaction trends
- Transaction analysis by category
- Customer and account-level insights
- Interactive charts, filters, and slicers

Project Objectives

- Explore banking transaction patterns.
- Monitor key transaction metrics.
- Identify trends and patterns in transaction activity.
- Present data through an interactive dashboard.

Files Included

- Power BI report (".pbix")
- Dashboard screenshots (if included)

Key Learnings

- Creating interactive dashboards in Power BI.
- Using measures and visualizations to analyze transaction data.
- Presenting business information in a clear, structured format.
